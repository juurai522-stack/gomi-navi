# ごみナビ｜恵那市 × 中津川市

恵那市・中津川市の公式ごみ分別資料と、自治体・民間の公式回収拠点情報をまとめたWeb検索サイトです。スマートフォン・パソコンのブラウザで利用できます。

## 主な機能

- 公式マニュアル由来の1,376品目検索
- 恵那市 / 中津川市切替
- 分別区分・出し方・公式資料表示
- 危険物（リチウム電池、スプレー缶等）の注意表示
- 回収・持込場所46拠点（自治体＋民間）
- バロー、DCM、エコファミリー、東海資源の公式確認済み回収情報
- 民間 / 自治体 / 24時間フィルター
- 「現在地から行く」Google Mapsルート
- 自治体問い合わせ先とワンタップ電話
- 令和8年度ごみ収集カレンダー / 地区別検索への直リンク
- 情報源・最終確認日・公式情報へのリンク
- 付属スクリプトによる公式ページ更新確認

## 起動方法

### 推奨：ローカルサーバー

```bash
python start_server.py
```

表示されたURL（通常 `http://localhost:8000`）をブラウザで開いてください。
位置情報機能は `localhost` での利用を推奨します。

### 簡易表示

`index.html` を直接開くこともできます。ただしブラウザによっては位置情報が制限されます。

## Vercelで公開

このリポジトリは、そのままVercelへインポートできる静的サイトです。

1. Vercelで「Add New → Project」を開く
2. このGitHubリポジトリを選択する
3. Framework Presetは「Other」、Root Directoryはリポジトリ直下のままにする
4. Build CommandとOutput Directoryは空欄のまま「Deploy」を実行する

GitHub連携後は、既定ブランチへの更新が自動的に本番サイトへ反映されます。

## GitHub Pagesで公開（推奨）

1. GitHubで公開リポジトリを作成する
2. このフォルダの内容をリポジトリの `main` ブランチへ登録する
3. リポジトリの「Settings → Pages」を開く
4. Sourceを「Deploy from a branch」、Branchを「main / (root)」にして保存する
5. 発行された `https://ユーザー名.github.io/リポジトリ名/` をロイロノートのWebカードに登録する

`.nojekyll` を含むため、GitHub Pagesでそのまま静的サイトとして配信できます。

## 注意

自治体公式サービスではありません。民間店舗の営業時間・回収内容・臨時休業は変更されることがあります。アプリ内の「公式情報」リンクを最終確認として使用してください。
